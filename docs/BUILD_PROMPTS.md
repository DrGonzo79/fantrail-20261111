# Phased build prompts

1. **Concierge inventory:** Build an authenticated editor for one event with source URL, last-verified timestamp, hours, zone and publish state. Add duplicate detection suggestions but require human approval. Test stale and conflicting sources.
2. **Consent-safe check-ins:** Replace demo codes with short-lived signed activation tokens, idempotency keys, explicit consent version, abuse throttles and aggregate-only sponsor queries. Threat-model replay, sharing and staff scans.
3. **Recap workflow:** Let producer and operator pre-agree metric definitions, freeze a campaign, export an immutable one-page recap, and show rejected/duplicate scans. Add tracing and audit logs.
4. **Distribution and quest:** Add partner embeds, editorial/promoted labels, multi-stop quest rules and prize eligibility only after two paid single-pin pilots. Never claim footfall lift without a valid baseline.
